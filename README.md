# Conciergerie Casablanca Heaven

Landing page premium basée sur le code Conciergerie Zenata.

## Modifier les biens affichés

Éditer : `assets/properties-heaven.js`

Pour ajouter un lien Airbnb :

```js
airbnbUrl: "https://www.airbnb.fr/rooms/XXXX"
```

Pour Booking :

```js
bookingUrl: "https://www.booking.com/hotel/ma/XXXX.html"
```

## Admin finance

Le dossier `admin-finance/` est conservé dans le projet, mais il n'est pas mis en avant dans la navigation de la landing page.
